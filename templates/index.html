● QUESTIONS

Frequently asked

What is SwarmSentriAI?

SwarmSentriAI is a multi-agent cybersecurity system that analyzes suspicious URLs using specialized security agents and threat-intelligence evidence.

Which threats can it analyze?

The current security swarm focuses on phishing, malware, scam patterns, and broader cyber-risk indicators associated with a URL.

Which threat-intelligence sources does it use?

SwarmSentriAI currently uses VirusTotal and urlscan.io to collect available reputation and URL-related security evidence.

How does the multi-agent system work?

A URL Security Agent first collects available threat-intelligence evidence. Specialist agents then analyze the URL independently, and the Security Decision Agent aggregates their findings.

What does the final verdict mean?

The current decision system can return Allow, Warn, or Block based on the aggregated specialist risk scores and configured decision thresholds.

Does it submit URLs for new urlscan.io scans?

No. The current implementation searches for available existing public urlscan.io results rather than submitting a new scan.

Does a low-risk result guarantee that a URL is safe?

No. The verdict is based on the evidence available to the system at scan time. A low-risk result should not be treated as a guarantee that a URL is completely safe.

What makes it different from a single URL scanner?

Instead of relying on one analysis path, the system combines threat intelligence with multiple specialized security perspectives before producing its final verdict.
